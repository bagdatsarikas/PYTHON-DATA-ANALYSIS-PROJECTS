## Overview

A collection of intermediate and advanced Python data analysis
projects focused on real-world business problems, exploratory
data analysis, statistical analysis, and data visualization.

The repository aims to transform raw data into meaningful
business insights using structured, reusable, and readable
Python code.

## Technical Skills

### Pandas

- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Missing value and duplicate handling
- Data transformation and manipulation
- Filtering, sorting, and indexing
- Grouping and aggregation
- Merging and joining datasets
- Pivot tables
- Date and time analysis
- Business performance analysis

### NumPy

- Array creation and manipulation
- Indexing and slicing
- Vectorized operations
- Conditional operations
- Numerical and statistical calculations
- Business metric calculations

### Matplotlib

- Bar and line charts
- Histograms and box plots
- Scatter plots
- Pie charts
- Subplots and figure customization
- Business data visualization



## Project Structure

Each project includes:

- Business background and objectives
- Original dataset
- Practical business requirements
- Data cleaning and preprocessing
- Python source code
- Exploratory data analysis
- Data visualizations
- Business insights and findings
- Project documentation

## Programming Approach

- Function-based and modular programming
- Reusable and readable Python code
- Exception handling where necessary
- Structured data analysis workflows
- Automated execution using the main() function
- Standalone executable Python programs
