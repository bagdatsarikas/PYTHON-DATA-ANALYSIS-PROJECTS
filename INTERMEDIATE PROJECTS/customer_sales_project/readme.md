## 01 — Commercial Retail Sales Analysis

An exploratory data analysis project focused on retail sales,
customer behavior, product performance, and profitability
using Pandas, NumPy, and Matplotlib.

### Dataset

- 40,000 transaction records
- 17 columns
- Sales period: 2024–2025
- Realistic synthetic commercial data

### Business Analysis

- Revenue and profitability
- Product and category performance
- Customer purchasing behavior
- Regional sales performance
- Sales channel comparisons
- Monthly sales trends
- Descriptive statistical analysis

### Technical Approach

- Pandas for data manipulation and analysis
- NumPy for numerical and statistical calculations
- Matplotlib for data visualization
- Reusable Python functions
- Meaningful code comments and analytical findings
- Integrated program execution using `main()`

**Level:** Beginner to Intermediate  
**Status:** In Progress
